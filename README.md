# 📦 StockFlow — Inventory & Sales Management System

**StockFlow** is a web application designed to manage inventory and sales, providing an overview of products, stock levels and inventory value through a clean and intuitive dashboard.

This project is being developed as part of my software development portfolio, focusing on full-stack development, database integration and business management solutions.

## 🚀 Features

### 📊 Dashboard
- Overview of registered products.
- Low-stock indicators.
- Inventory value calculation.
- Summary of inventory information.

### 📦 Inventory Management
- Product listing.
- Product search.
- Inventory overview.
- Product management interface.

### 🛒 Sales
- Sales module (under development).

### 📈 Reports
- Reports module (under development).

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- PostgreSQL

### Installation

Clone the repository:

```bash
git clone https://github.com/mishellAC/stockflow-inventory-sales.git
```

Navigate to the project directory:

```bash
cd stockflow-inventory-sales
```

### Backend

```bash
cd backend
npm install
```

Configure your environment variables in a `.env` file.

Start the backend server using the configured development script.

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.
